## 🧠 Project Description

This project presents a **simulation-based performance comparison between Bluetooth 5.0 Low Energy (BLE) and Wi-Fi 6 (IEEE 802.11ax)**.

The project uses **Python and SimPy discrete-event simulation** to compare both wireless technologies under similar conditions and analyze their performance, reliability, energy efficiency, latency, and communication range. :contentReference[oaicite:2]{index=2}

The project includes:
- **Bluetooth 5.0 LE simulation**
- **Wi-Fi 6 simulation**
- **IoT sensor network scenario**
- **High-speed network scenario**
- **Communication range analysis**
- **Scalability analysis**
- **Performance comparison graphs**
- **HTML-based analysis report**

## 🎯 Key Findings

- 📶 **Wi-Fi 6** provides significantly higher throughput.
- 🔋 **Bluetooth LE** provides better energy efficiency.
- ⚡ **Bluetooth LE** shows lower latency in the analyzed scenarios.
- 📡 **Wi-Fi 6** provides better performance for high-speed and larger network applications.
- 🔌 **Bluetooth LE** is suitable for low-power IoT and wearable devices. :contentReference[oaicite:4]{index=4}
